## 💎 Design Philosophy & Aesthetic

The website is crafted with an **Apple-level minimalism + futuristic medical technology + luxury international healthcare** visual language:
- **Color Palette:** Deep navy & near-black base (`#030712`), illuminated by brand cyan/teal (`#1dbcb5`), glowing accents (`#23d2ca`, `#26d1ca`), and frosty translucent layers.
- **Typography:**
  - **Space Grotesk (400–700):** Headings, Logo Wordmark (`AMRIZA`), and Display Badges / Labels.
  - **DM Sans (400–700):** Body copy, Buttons, Navigation links, and Form inputs.
- **Glassmorphism:** Multi-layered frosted glass panels with `backdrop-filter: blur(20px)`, thin borders (`rgba(29, 188, 181, 0.16)`), and ambient radial lighting.
- **Micro-Interactions:**
  - Custom lerped desktop cursor with magnetic expansion on buttons and cards (automatically disabled on touch devices).
  - Web Audio API synthesized glass chimes and subtle feedback (zero external audio files).
  - 3D card tilt physics reacting to cursor position.
